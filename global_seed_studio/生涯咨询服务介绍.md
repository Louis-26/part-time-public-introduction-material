# 辅导背景及规范

深耕课业辅导3年，致力于帮助大家冲A，总教学课时数超过500小时。目前是海马和新东方的专业兼职老师,也创建了自己的辅导平台尝试自己招生。我们平台是**Global Seed**, 我们目前有20多位专业辅导老师，可覆盖文、理、工、商等领域的大多数课程辅导。如果本人无法参与辅导，我可以帮忙找其他擅长相关科目的老师来辅导。一般可以辅助课件梳理，作业辅导，考前突击，但拒绝任何形式的代写代考。

# 咨询辅导平台收费标准

本平台致力于提供不低于国内一线留学机构(海马课堂/新东方/路觅教育)的辅导质量，同时提供相比之下更低的学费(目前定为大型机构的三分之二左右)。实现从需求发起到结果落地的完美交付。我们会持续吸纳全球更低的优质老师，为大家的学业道路保驾护航。咨询辅导的费用目前是学术辅导的三分之二，后期可能会适当调整。  
我们的课时没有过期时间也没有科目或辅导类型限制，一旦购买，终生有效，可以在任何时候对于任何科目的任何辅导需求使用。如果不是课程质量问题，我们原则上不接受课程的退款。所以请大家在购买课时前三思，确认自己到底总共需要多少课时。此外，本平台最低购买课时单位为**0.5**小时。
